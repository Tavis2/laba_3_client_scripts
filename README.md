# Лабораторная работа № 3

Доска публикаций на HTML, CSS и обычном JavaScript.

## Запуск
Распакуйте архив и откройте `index.html` в браузере. Для запросов нужен интернет.
Установка пакетов и сервер не требуются.

## Реализация
- `index.html` — кнопка загрузки, список, форма с подписями и сообщения.
- `style.css` — простое оформление страницы.
- `app.js` — два обработчика событий: GET и POST.

GET загружает пять записей через fetch и async/await. POST отправляет JSON
с title, body и userId: 1, выводит заголовок и ID из ответа.
Поля проверяются через trim(). Используются preventDefault(), response.ok,
try/catch/finally. Во время запроса кнопка отключена и показан статус.
После ошибки можно повторить запрос. Данные выводятся через textContent.
JSONPlaceholder не сохраняет новые записи постоянно.
## Результаты проверки
Проверено в Chromium:
- GET: на странице отображаются пять публикаций с заголовками и текстом.
- Пустые поля и одни пробелы: появляется ошибка, запрос не отправляется.
- POST: пробелы по краям удаляются, отправляется JSON с userId: 1;
  после успешного ответа выводятся заголовок и ID публикации.
- HTTP 404 при загрузке и HTTP 500 при создании: появляется сообщение с кодом ошибки.
- Сетевой сбой: появляется понятное сообщение с предложением повторить запрос.
- После завершения запроса кнопка снова доступна.

Ответы и сбои воспроизведены перехватом запросов в тестовом браузере.
Реальные GET (200) и POST (201) проверялись при подготовке исходной версии.
Для ручной проверки 404 временно замените адрес GET на
https://jsonplaceholder.typicode.com/postz, обновите страницу и нажмите
«Загрузить публикации». Затем восстановите адрес с `/posts?_limit=5`.
